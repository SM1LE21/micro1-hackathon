Is your GDPR paperwork
still true?

  • Every product with users in the EU must keep a record of its personal data — and actually delete it on request.
  • That record is written by hand. The code keeps moving. Regulators fine the gap: €300,000 for deactivating accounts instead of deleting them.
Why we check what we check: GDPR Art. 30 & 17, the EDPB 2026 erasure report, CNIL SAN-2021-008 — distilled into the verifier's rule set, sources cited in the repo.

art30 writes the technical half — from the code

  • An agent reads your repository's files and drafts the record: what personal data lives where, and whether closing an account really deletes it.
  • A deterministic verifier re-checks every claim against the code — rejected claims go back with the reason and the exact line.
  • Every cell cites file:line. Legal fields stay empty for your lawyer. A person approves before anything renders.
It never says "compliant" — it shows you what the code does.
