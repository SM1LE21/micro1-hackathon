art30 — the technical half of a GDPR
Article 30 record, read out of the code

  • The founder of an EU SaaS is asked for the record of processing — by a buyer's lawyer, a DPO, an authority. It was written by hand months ago. The code moved.
  • EDPB, 2026: controllers handling erasure requests don't use their records. CNIL: €300,000 for deactivating accounts instead of deleting — that decision is rebuilt as eval case S02.
What is checked, and why: GDPR Art. 30(1) & Art. 17 + the EDPB 2026 erasure report + CNIL SAN-2021-008, distilled into the verifier's rule set with sources cited in docs/research/gdpr-sources.md.

An agent that reads; a verifier it cannot skip

  • Three read-only tools — list_tree · read_file · grep — and one way out: submit_record.
  • Every “erased” claim is checked deterministically (stdlib ast): is there a static call path from the erasure entry point to a deletion primitive for that store? A struck claim returns with reason + line; the model must answer it.
  • A person approves before anything renders. Legal cells stay empty. It never says “compliant”.
  • Baseline: same model, same instruction bytes, same tools, five attempts — verifier and gate removed. Ships as a skill.
One core, three surfaces: CLI · local web UI (drives the CLI) · agent skill.

Evidence, or it didn't happen

  • Changelog, 7 rows, incidents kept. Biggest contributor: the closed loop itself — the citation rule becomes feedback instead of a render wall (S10: 1/3 → 3/3).
  • Removed experiment: four real repositories, vendored on day one, never hand-labelled, dropped. An eval case is its label, not its repository.
  • make setup && make smoke && make eval-replay-local — no API key; the verifier re-runs over all 80 recorded submissions and results/metrics.json returns byte for byte.
  • Every trace committed, failures included — and the coding-agent session that built this repo, rendered in traces/.
Hot take: the reliability work was not making the model smarter — it was implementing each deterministic rule exactly once, and wiring its answer back as feedback instead of a wall.
