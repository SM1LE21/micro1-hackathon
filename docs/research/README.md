# Research

Source material behind the spec. Each file ends with a Sources table (ID, title, URL, accessed date, what it was used for); verbatim legal texts and documentation excerpts live under `sources/` with the URL in the header. Every file was written by a research agent and then checked by an independent verifier that re-fetched every source; the verifier's findings were applied before commit.

| File | What it answers |
|---|---|
| `gdpr-sources.md` | What Art. 30 requires, what erasure means, what regulators say about backups and anonymisation, what code can and cannot evidence |
| `ai-act-sources.md` | The gated AI Act extension: articles, the timeline as of August 2026, what code can evidence |
| `framework-behaviour.md` | The Django, SQLAlchemy, S3, Redis, Stripe, Sentry and Python `ast` facts the verifier's rules rest on |
| `prior-art.md` | Bearer, Privado, Fides, commercial data-mapping suites, academic work; what we borrow and where we differ |

Judge-facing material derived from this lives in `docs/judging/`.
